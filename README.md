# Secure Vote

Secure Vote est une application web PHP/MySQL permettant la transmission sécurisée des résultats électoraux.

## Fonctionnalités

- Authentification des utilisateurs
- Gestion des utilisateurs
- Gestion des bureaux de vote
- Gestion des partis politiques
- Saisie des résultats électoraux
- Transmission des procès-verbaux
- Tableau de bord administrateur
- Journalisation des actions

## Technologies utilisées

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- PDO

## Installation

1. Copier le dossier `secure_vote` dans `htdocs`
2. Créer la base de données avec le fichier `database/secure_vote.sql`
3. Modifier `includes/config.php` selon votre serveur
4. Ouvrir dans le navigateur :

```text
http://localhost/secure_vote/login.php
```
